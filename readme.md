## Faculdade 

Repositório criado para armazenar aividades, exercícios, projetos e trabalhos desenvolvidos durante o terceiro semestre da minha graduação em Análise e Desenvolvimento de Sistemas na Fatec Ipiranga.

## Matérias

### Estrutura de Dados  
Desenvolvidas implementações e exercícios utilizando a linguagem C, com foco nos principais conceitos de estruturas de dados e algoritmos.  
- Ponteiros e alocação dinâmica de memória;
- Structs e organização de dados;
- Pilhas (Stacks);
- Filas (Queues);
    
Tecnologias utilizadas: 
- Linguagem C
- GCC
- Visual Studio Code

### Laboratorio de Banco de Dados  
Desenvolvidos projetos e atividades voltados à modelagem, criação e manipulação de bancos de dados relacionais, utilizando SQL para armazenamento e gerenciamento de informações.
- Modelagem de dados;
- Comandos DDL (CREATE, ALTER e DROP);
- Comandos DML (INSERT, UPDATE e DELETE);
- Consultas SQL com SELECT;

Tecnologias utilizadas: 
- MySQL
- SQL
- MySQL Workbench

### Programação Orientada a Objetos
Nesta disciplina foram desenvolvidos projetos utilizando Java, aplicando os principais conceitos da Programação Orientada a Objetos para a construção de sistemas organizados, reutilizáveis e de fácil manutenção.
- Classes e objetos;
- Tratamento de exceções;
- Padrão DAO (Data Access Object);
- Integração com banco de dados utilizando JDBC;

Tecnologias utilizadas: 
- Java
- JDBC
- MySQL
- Apache NetBeans
